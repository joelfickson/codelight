---
name: explore-codebase
description: Understand an unfamiliar codebase before planning or implementing changes across any language or framework.
---

Read project instructions and the README. Identify the language, manifests, lockfiles, build commands, tests, and CI workflows without assuming a particular stack.

Inspect the working tree before editing. Preserve existing user changes. Trace the relevant entry points, data flow, and call sites using search and targeted file reads.

Summarize the architecture relevant to the request, then choose the smallest change consistent with existing conventions. Ask only about ambiguities that materially affect the result. Never invent paths or APIs.
